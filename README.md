# 🎨 Overview

**Portfolio — Full 3D Animated Website** is a modern personal portfolio template designed for developers, designers, freelancers, and creative professionals.

Featuring a dynamic **Three.js powered 3D scene**, animated gradients, scroll-triggered reveals, and beautiful interactions, this project helps you showcase your work in a memorable way.

No frameworks. No backend.

Just pure **HTML, CSS, JavaScript, and Three.js**.
